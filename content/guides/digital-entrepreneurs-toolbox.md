# The Digital Entrepreneur's Toolbox

A concise list of useful tools for building, launching, analyzing, and growing digital products.

| Type | Tool | Role | When |
| --- | --- | --- | --- |
| UI components | [21st.dev](https://21st.dev/) | Provides ready-made UI components for React and Next.js. | When building a polished web interface quickly |
| Mobile attribution | [AppsFlyer](https://www.appsflyer.com/) | Measures mobile acquisition, attribution, and marketing performance. | When comparing campaigns, channels, and app-install sources |
| Authentication | [Clerk](https://clerk.com/) | Provides managed authentication and user management. | When a product needs sign-up, sign-in, and account flows |
| Mobile development | [Expo](https://expo.dev/) | Provides a platform for building iOS and Android apps with React Native. | When developing and releasing a cross-platform mobile app |
| Legal operations | [FoundersForm](https://foundersform.ai/) | Automates startup incorporation, cap table management, legal documentation, and investor due diligence readiness. | When incorporating an early-stage startup, issuing equity, or preparing legal docs for fundraising |
| Website builder | [Framer](https://www.framer.com/) | Designs, builds, and publishes responsive, design-driven websites and landing pages. | When launching marketing websites, landing pages, or product showcases quickly |
| AI interface design | [Google Stitch](https://stitch.withgoogle.com/) | Generates interface concepts and prototypes with AI. | When exploring screen ideas before implementation |
| Video generation | [HyperFrames](https://github.com/heygen-com/hyperframes) | Renders deterministic MP4 videos and motion graphics programmatically using HTML, CSS, and JavaScript. | When generating dynamic marketing videos, product demos, or automated video content |
| Payments | [iyzico](https://docs.iyzico.com/) | Provides online payment infrastructure for Türkiye. | When accepting local cards and online payments in Türkiye |
| Product management | [Linear](https://linear.app/) | Organizes projects, issues, and product roadmaps. | When planning releases and coordinating product work |
| Product analytics | [Mixpanel](https://mixpanel.com/) | Analyzes user behavior, funnels, and retention. | When learning how people adopt and use a digital product |
| Design research | [Mobbin](https://mobbin.com/) | Collects UI/UX references and flows from real applications. | When researching established interaction patterns and user journeys |
| Workflow automation | [n8n](https://n8n.io/) | Connects apps, APIs, and AI services to build visual workflow automations and integrations. | When automating operational workflows, data sync, or AI-driven tasks across systems |
| Web framework | [Next.js](https://nextjs.org/) | Provides a React-based full-stack web framework. | When building a production web application or content site |
| Documentation | [Notion](https://www.notion.so/) | Combines notes, documentation, knowledge bases, and project planning. | When centralizing product knowledge and team workflows |
| Customer messaging | [OneSignal](https://onesignal.com/) | Provides push notifications and customer messaging infrastructure. | When re-engaging users with timely product messages |
| AI automation | [OpenClaw](https://openclaw.ai/) | Provides AI agents and work automation capabilities. | When delegating repeatable digital tasks to AI workflows |
| Product analytics | [PostHog](https://posthog.com/) | Combines analytics, session replay, feature flags, and experiments. | When one platform should cover measurement and product experimentation |
| API directory | [Public APIs](https://github.com/public-apis/public-apis) | Curates a collective list of free and public APIs for software development and prototyping. | When researching third-party data sources, service integrations, or prototyping an MVP |
| Subscription management | [RevenueCat](https://www.revenuecat.com/) | Manages mobile subscriptions and in-app purchases across app stores. | When selling and monitoring subscription access in mobile apps |
| Market intelligence | [Sensor Tower](https://sensortower.com/) | Provides mobile market, keyword, and competitor intelligence. | When evaluating an app category, competitors, or market demand |
| UI components | [shadcn/ui](https://ui.shadcn.com/) | Provides customizable, code-owned React components. | When building a consistent interface without a rigid component library |
| Agent skills | [Skills.sh](https://www.skills.sh/) | Catalogs reusable skills for AI coding agents. | When looking for an existing agent workflow before creating one |
| Payments | [Stripe](https://docs.stripe.com/) | Provides global online payment and subscription infrastructure. | When accepting international payments or recurring subscriptions |
| Paywall optimization | [Superwall](https://superwall.com/) | Creates and tests mobile paywalls. | When improving mobile subscription conversion through experiments |
| Backend platform | [Supabase](https://supabase.com/) | Provides databases, authentication, storage, and backend services. | When a product needs a managed backend that can be launched quickly |
| Deployment | [Vercel](https://vercel.com/) | Deploys and hosts web applications with preview environments. | When publishing frontend applications and reviewing changes before release |
